# Aprovação Passo a Passo

Estrutura principal:
- `frontend/html` para páginas HTML
- `frontend/css` para estilos
- `frontend/js` para scripts
- `frontend/images` para imagens e ícones
- `backend/java` para código Java
- `database` para scripts SQL

A página ativa da plataforma bancária está em `frontend/html/bancos.html`.
